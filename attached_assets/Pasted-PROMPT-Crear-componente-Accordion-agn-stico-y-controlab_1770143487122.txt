PROMPT – Crear componente Accordion agnóstico y controlable
Quiero que generes un componente Accordion reutilizable, agnóstico a la data y desacoplado de la lógica de control.
 El componente NO debe asumir ningún tipo de contenido, ni estructura interna del header o body.
El Accordion debe funcionar correctamente en modo no controlado, controlado por props y controlado externamente mediante un hook.

1. Requisitos funcionales
El Accordion debe cumplir obligatoriamente con lo siguiente:
Permitir abrirse y cerrarse:


Por interacción interna (click en el header)


Por props (isOpen)


De forma imperativa desde fuera mediante un hook


Emitir eventos:


Cada vez que se abre o se cierra


Cada vez que el body se renderiza


Permitir:


Renderizar el header externamente


Renderizar el body externamente


Forzar el re-render del body desde fuera


No usar refs, forwardRef ni useImperativeHandle


No contener lógica global ni conocimiento de otros accordions



2. API del componente Accordion (contrato de props)
type AccordionProps = {
  id: string;

  controller?: AccordionController;

  isOpen?: boolean;
  defaultOpen?: boolean;

  callbacks?: {
    onToggleAccordion?: (id: string, isOpen: boolean) => void;
    onRenderBody?: (id: string) => void;
  };

  layout?: {
    widthMode?: "full" | "auto" | "fixed";
    width?: number;
    minWidth?: number;

    heightMode?: "full" | "auto" | "fixed";
    height?: number | "auto";
    minHeight?: number;
  };

  header: {
    renderType: "component";
    render: ReactNode | Component;

    heightMode?: "full" | "auto" | "fixed";
    height?: number | "auto";
    minHeight?: number;
  };

  body: {
    renderType: "component";
    render: ReactNode | Component;

    heightMode?: "full" | "auto" | "fixed";
    height?: number | "auto";
    minHeight?: number;

    behaviors?: {
      scroll?: boolean;

      renderComponentStrategy?: "once" | "always";
      // once: el body se monta una sola vez
      // always: el body se desmonta y monta en cada toggle
    };
  };
};


3. Hook de control externo (obligatorio)
Debe existir un hook independiente:
const controller = useAccordionController();

API del hook
type AccordionController = {
  open: (id: string) => void;
  close: (id: string) => void;
  toggle: (id: string) => void;

  forceRenderBody: (id: string) => void;

  isOpen: (id: string) => boolean;
};

Reglas del hook
El hook:


No renderiza nada


No depende del UI


No conoce la estructura interna del Accordion


El Accordion:


Se registra automáticamente en el hook usando su id


No depende del hook para funcionar


El hook es opcional



4. Reglas de control de estado (MUY IMPORTANTE)
Si isOpen es provisto:


El Accordion se comporta como componente controlado


No debe manejar estado interno


Si isOpen NO es provisto:


Usa estado interno con defaultOpen


Si controller existe:


Debe permitir abrir, cerrar y forzar render desde fuera


El body:


NO debe renderizarse cuando el accordion está cerrado


Debe respetar renderComponentStrategy



5. Estrategia correcta para re-renderizar el body
El Accordion debe manejar un renderKey interno:
const [renderKey, setRenderKey] = useState(0);

Cuando el hook ejecuta:
controller.forceRenderBody(id);

El Accordion debe:
setRenderKey(prev => prev + 1);

Y renderizar el body así:
{isOpen && (
  <BodyComponent key={renderKey} />
)}

No usar refs ni efectos imperativos.

6. Ejemplo de uso – Control interno
<Accordion
  id="accordion-1"
  defaultOpen={false}
  header={{
    renderType: "component",
    render: <Header />
  }}
  body={{
    renderType: "component",
    render: <Body />,
    behaviors: {
      renderComponentStrategy: "once"
    }
  }}
/>


7. Ejemplo de uso – Control por props
const [open, setOpen] = useState(false);

<Accordion
  id="accordion-2"
  isOpen={open}
  callbacks={{
    onToggleAccordion: (_, state) => setOpen(state)
  }}
  header={{
    renderType: "component",
    render: <Header />
  }}
  body={{
    renderType: "component",
    render: <Body />
  }}
/>


8. Ejemplo de uso – Control externo con hook
const controller = useAccordionController();

<button onClick={() => controller.open("accordion-3")}>
  Open
</button>

<button onClick={() => controller.forceRenderBody("accordion-3")}>
  Refresh body
</button>

<Accordion
  id="accordion-3"
  controller={controller}
  header={{
    renderType: "component",
    render: <Header />
  }}
  body={{
    renderType: "component",
    render: <Body />,
    behaviors: {
      renderComponentStrategy: "always"
    }
  }}
/>
