Quiero un componente Grid Engine declarativo, agnóstico a la data, que incluya un sistema interno de estado y exponga un hook para controlarlo externamente.
El componente:
No obtiene datos.


No pagina.


No sabe si hay más datos.


No conoce cantidades totales.


Solo organiza layout.


Calcula capacidad.


Detecta final de scroll.


Maneja su propio state interno.


Expone un hook tipo setState.

2️⃣ State Interno del Grid
El Grid debe manejar internamente:
'idle' | 'loading' | 'empty' | 'error'

Estado inicial: "idle"

3️⃣ Hook Obligatorio Expuesto
Debe existir un hook exportado:
const {
  setState,
  getState,
  refreshLayout
} = useGridController()


🔹 setState(newState)
Cambia el estado interno del Grid.
Ejemplo externo:
const { setState } = useGridController()

setState("loading")


🔹 getState()
Devuelve el estado actual.

🔹 refreshLayout()
Fuerza:
Recalcular columnas


Recalcular filas


Reemitir onCapacityChange


No toca data.
 Solo layout.

4️⃣ Flujo Correcto con Infinite Scroll
Usuario llega al final.


Grid detecta scroll final.


Grid dispara onReachEnd().


Padre llama:


setState("loading")

Padre agrega más data.


Padre llama:


setState("idle")

El Grid nunca decide nada sobre los datos.

5️⃣ Regla Crítica
El Grid solo puede disparar onReachEnd() si:
state === "idle"

Si está en "loading":
 → no dispara evento.
