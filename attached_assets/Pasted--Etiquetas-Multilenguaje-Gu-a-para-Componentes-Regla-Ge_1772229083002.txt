# Etiquetas Multilenguaje — Guía para Componentes

## Regla General

Cuando un componente muestra **labels de traducción** (textos visibles al usuario), debe:

1. Usar la prop `labelI18n` de tipo `MultiLanguageLabel` (importada desde la librería GC-UI-COMPONENTS).
2. Ser **reactivo al idioma**: cuando el usuario cambia de idioma, el componente debe actualizar sus textos automáticamente sin necesidad de recargar la página.

---

## Interfaz `MultiLanguageLabel`

```typescript
import type { MultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/types";

interface MultiLanguageLabel {
  [languageCode: string]: any;
  default: string;       // Obligatorio — texto de fallback
  metadata?: any;        // Opcional — información adicional
}
```

**Ejemplo:**
```typescript
const label: MultiLanguageLabel = {
  en: "Trips",
  es: "Viajes",
  default: "Trips"
};
```

---

## Función de Resolución

Para obtener el texto en el idioma activo, usar `resolveMultiLanguageLabel`:

```typescript
import { resolveMultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/utils";

const texto = resolveMultiLanguageLabel(label, lang); // "Viajes" si lang="es"
```

**Orden de resolución:**
1. Coincidencia exacta del código de idioma (`es`, `en`)
2. Prefijo del idioma (`en` para `en-US`)
3. Cualquier clave que empiece con el prefijo
4. Fallback a `default`
5. Último recurso: primer valor string encontrado

## Cómo Implementar en un Componente

### Paso 1 — Definir la prop `labelI18n`

```typescript
import type { MultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/types";

interface MiComponenteProps {
  labelI18n: MultiLanguageLabel;
}
```

### Paso 2 — Obtener el idioma activo

Usar el hook `useLanguage` del proyecto para obtener `lang`:

```typescript
import { useLanguage } from "@/providers/LanguageProvider";
```

### Paso 3 — Resolver el label en el render

```typescript
import { resolveMultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/utils";

function MiComponente({ labelI18n }: MiComponenteProps) {
  const { lang } = useLanguage();
  const textoResuelto = resolveMultiLanguageLabel(labelI18n, lang);

  return <span>{textoResuelto}</span>;
}
```

Al depender de `lang` (que viene del contexto reactivo de `LanguageProvider`), el componente se re-renderiza automáticamente cuando el usuario cambia de idioma.

## Ejemplo Completo

```typescript
import type { MultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/types";
import { resolveMultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/utils";
import { useLanguage } from "@/providers/LanguageProvider";

interface FilterButtonProps {
  labelI18n: MultiLanguageLabel;
  onClick: () => void;
}

function FilterButton({ labelI18n, onClick }: FilterButtonProps) {
  const { lang } = useLanguage();
  const label = resolveMultiLanguageLabel(labelI18n, lang);

  return (
    <button onClick={onClick} data-testid="button-filter">
      {label}
    </button>
  );
}

// Uso:
<FilterButton
  labelI18n={{ en: "Apply Filters", es: "Aplicar Filtros", default: "Apply Filters" }}
  onClick={handleApply}
/>
```

## Ejemplo con Listas de Items

Para listas donde cada item tiene su propia etiqueta traducida, usar `ItemWithMultiLanguageLabel`:

```typescript
import type { ItemWithMultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/types";
import { resolveMultiLanguageLabel } from "GC-UI-COMPONENTS/client/src/lib/ui-library/utils";
import { useLanguage } from "@/providers/LanguageProvider";

const opciones: ItemWithMultiLanguageLabel[] = [
  { id: "driver", label: { en: "Driver", es: "Conductor", default: "Driver" } },
  { id: "fleet",  label: { en: "Fleet",  es: "Flota",     default: "Fleet" } },
];

function ListaOpciones({ items }: { items: ItemWithMultiLanguageLabel[] }) {
  const { lang } = useLanguage();

  return (
    <ul>
      {items.map((item) => (
        <li key={item.id}>
          {resolveMultiLanguageLabel(item.label, lang)}
        </li>
      ))}
    </ul>
  );
}
```

## Helpers Disponibles

| Función | Descripción |
|---|---|
| `resolveMultiLanguageLabel(label, lang)` | Resuelve un `MultiLanguageLabel` al string del idioma activo |
| `createSimpleLabel(text)` | Crea un `MultiLanguageLabel` con solo `default` |
| `createMultiLanguageLabel({ en, es })` | Crea un `MultiLanguageLabel` completo con fallback automático |
| `isMultiLanguageLabel(value)` | Type guard — verifica si un valor es `MultiLanguageLabel` |

Todas se importan desde:
```typescript
import {
  resolveMultiLanguageLabel,
  createSimpleLabel,
  createMultiLanguageLabel,
  isMultiLanguageLabel
} from "GC-UI-COMPONENTS/client/src/lib/ui-library/utils";
```

## Referencia con Componentes de la Librería

La librería GC-UI-COMPONENTS ya usa `MultiLanguageLabel` internamente en varios componentes:

- **NavigationSidebar**: cada `NavigationItem` acepta `i18n?: MultiLanguageLabel` para traducir el label del menú.
- **TagSelector**: los items (`TagItem`) usan `label: MultiLanguageLabel` y el prop `allLabel?: MultiLanguageLabel`.

Estos componentes resuelven automáticamente el idioma usando el contexto de idioma de la librería o el `langOverride` que se les pase.

---

## Checklist

- [ ] La prop de texto visible se llama `labelI18n` y es de tipo `MultiLanguageLabel`
- [ ] El componente importa `useLanguage` para obtener `lang`
- [ ] El componente usa `resolveMultiLanguageLabel(labelI18n, lang)` para resolver el texto
- [ ] Al cambiar de idioma, el texto se actualiza automáticamente (reactividad vía contexto)
- [ ] El `MultiLanguageLabel` siempre incluye la clave `default` como fallback obligatorio
